# Whitepace Landing Page

A pixel-perfect reproduction of the Whitepace SaaS landing page from Figma, built with Next.js, TypeScript, and Tailwind CSS.

**Live Demo:** [your-vercel-url]
**Figma Design:** [https://www.figma.com/community/file/1156860863353724933]

## Tech Stack
- Next.js 15 (App Router)
- TypeScript
- Tailwind CSS v4

## Features
- 14 sections
- Responsive at 5 breakpoints (320px, 768px, 1024px, 1280px, 1536px)
- CSS scroll snap carousels for pricing and testimonials
- Decorative SVG graphics with responsive positioning
- Custom design tokens matching Figma

## What I Learned
- Translating Figma designs to pixel-perfect code
- Responsive layout at every breakpoint
- CSS scroll snap for mobile carousels
- Complex absolute positioning for decorative elements
- Working with SVG exports from Figma
